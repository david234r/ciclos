# Ciclos

## Descripción: 
Este proyecto está enfocado en el aprendizaje y aplicación de ciclos (bucles), estructuras condicionales y funciones/métodos en Java, además del desarrollo de un menú interactivo en consola. También promueve el uso de herramientas colaborativas para facilitar el trabajo en equipo de forma remota. 

 - Uso de **ciclos `while` y `for`** para la iteración de secuencias y cálculos repetitivos.
 - Implementación de **funciones y métodos** modulares para organizar cada algoritmo.
 - Creación de un repositorio en GitHub
 - Personalización del README.md
 - Exposición explicando las preguntas teoricas y los codigos

 
## Instrucciones para la ejecución del programa
### Requisito previo: Verificar que Java esté instalado

Asegúrate de tener el compilador de Java instalado y configurado. Ejecuta en tu terminal Bash:

    javac -version

Ejecuta el compilador de Java (`javac`) en la carpeta donde se encuentra el archivo del programa, pasándole el nombre del archivo fuente completo:

    javac MenuPrincipal.java

Si todo es correcto, no mostrará ningún mensaje en pantalla, pero se creará un nuevo archivo llamado: `MenuPrincipal.class`

Llama a la Máquina Virtual de Java (`java`) indicando únicamente el **nombre de la clase**, sin la extensión.

    java MenuPrincipal

También para mayor agilidad puedes poner el siguiente comando para ejecutar el programa directamente sin digitar los comandos anteriores:

    javac MenuPrincipal.java && java MenuPrincipal

**Importante: al correr el programa te va a solicitar seleccionar una opción entre 1 y 5 para continuar ejecutándose.**
