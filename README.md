## Preguntas Teóricas

### Diapositiva 6: Ciclos - Teoría 1/3
1. ¿Cuál es la diferencia entre un ciclo `for`, un ciclo `while` y un ciclo `do-while`?
2. ¿Qué es un ciclo infinito y cómo se puede evitar?
3. ¿Cómo se pueden anidar ciclos en Java?
4. ¿Qué es el alcance (*scope*) de una variable dentro de un ciclo?

### Diapositiva 7: Ciclos - Teoría 2/3
1. Explique 3 palabras reservadas que se pueden usar en un ciclo (`break`, `continue`, `return`).
2. ¿Cómo se pueden usar los ciclos para procesar datos de entrada del usuario?
3. ¿Qué es un contador? ¿Qué tipos de variables de control conoce?
4. ¿Qué es una secuencia de escape y cómo se usa para resolver este taller?

### Diapositiva 8: Ciclos - Teoría 3/3
1. Explique tres atajos de teclado útiles para programar en VS Code.
2. ¿Qué es *overflow* y en qué parte del taller se puede presentar?
3. ¿Cómo se pueden personalizar los colores de la consola en Java?
4. Escriba 5 formas diferentes de definir ciclos infinitos en Java.
